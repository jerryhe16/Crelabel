Optional internal driver package
================================

If your organization has obtained an approved, unmodified Zebra printer driver
installer for internal employee use, rename it to ZebraDriverSetup.exe and place it
in this folder before running build.ps1.

Do not commit or redistribute ZebraDriverSetup.exe without confirming Zebra's EULA.
The normal Crelabel installer opens Zebra's official setup page when this file is absent.
